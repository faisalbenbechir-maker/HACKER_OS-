Network Lab

Learn the basic building blocks of computer networks.

IP Address

An IP address is a numerical identifier assigned to a device on a network.

Example: 192.168.1.10

DNS

DNS translates domain names into IP addresses so devices can find online services.

Example: example.com

Gateway

A default gateway connects your local network to other networks.

Example: 192.168.1.1

Router

A router forwards data between networks and helps devices connect to the internet.

Cyber Lessons

Start with the fundamentals. Learn one concept at a time.

01 — What is Cybersecurity?

Cybersecurity is the practice of protecting computers, networks, applications and data from digital threats.

02 — What is an IP Address?

An IP address identifies a device or network interface so data can be delivered to the correct destination.

03 — What is a Port?

A port is a logical communication endpoint used by network services. For example, HTTPS commonly uses port 443.

04 — What is Ethical Hacking?

Ethical hacking means testing systems with permission to discover weaknesses and help fix them.

05 — What is Malware?

Malware is software designed to harm devices, disrupt operations or access information without permission.

About HACKER OS

Learn. Explore. Protect.

HACKER OS is a cybersecurity education project for beginners. It introduces networking, digital safety, password security and ethical cybersecurity concepts through interactive learning tools.

This website is an educational simulation. It does not scan networks, access other devices, retrieve credentials or perform real-world attacks.
